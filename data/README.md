# PUBLIC DATA DIRECTORY - READ FIRST

Everything in this directory is served over GitHub Pages and visible from a public repository. Do not store or commit:

- Raw Google Form/Sheet exports, row-level surveys, pseudonymized household records
- Names, phone numbers, emails, exact addresses, house coordinates or photo identifiers
- Consent/opt-in logs or private hazard-referral notes
- Private zone boundary overlays that would reidentify participants
- Credentials, tokens, access keys or edit links to restricted documents

`public-map.json` is initially a pending manifest only. Publish a map only after review and documented disclosure checks. The display script is NOT a data-protection solution: hidden content in a public repository is still public.
